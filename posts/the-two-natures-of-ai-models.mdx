- **Memorised intelligence:** the model functioning as an extremely sophisticated query engine over learned information and patterns.
- **Latent intelligence:** something closer to genuine or “true” intelligence.
- Models are demonstrably getting “smarter,” while it remains difficult to describe **what exactly has become smarter**.
- Benchmarks show new tasks models can perform without necessarily revealing what underlying cognitive capability changed.
- What **new mental connections** has a newer model made that an older model couldn’t?
- What does it actually mean for a model to **reason**?
- When and how do models move from increasingly capable memorised intelligence toward latent intelligence?
- “Latent” as the intelligence that isn’t straightforwardly visible from benchmark scores.
- Like, do they memorize more things?
- And are they able to reason better?
- So what does it mean to reason exactly?
- And I don’t say that memorized intelligence is not real intelligence, okay?
- memorization is a clear part of human intelligence as well.
- But it is not the core of what makes us intelligent.
- But the second part is what you do with the memory.
- And so I think about this in terms of reactive intelligence, where things come at you from the external environment, and you react to it in certain ways based on the memory that you have already acquired from the past.
- But what happens when you encounter a completely new problem?
- How do you solve it?
- You have to reason through it, and that latent intelligence, I think, is the ability to reason through it.
- And what I want to get through this thing is to find the core loop, the core loop of intelligence, which is having a memory bank and having the reactivity and having the reasoning capability.
- Being reactive is like being able to take in information and then reason upon it and then produce the next steps and produce the plans of a next step, and then take that action, observe what changed, and then loop again and again and again.
- And this loop, I say, is what intelligence is, and this is the thing that we are trying to optimize for.
- But what is it about them that helps them reason more?
- Like, why can a smaller model not reason more?
- So what is it about reasoning models, reasoning itself, that requires longer loops versus smaller loops?
- And how do we narrow things down so that they need to think smaller?
- Or do we think that reasoning itself is an irreducible process?
- So can we reduce it down to a problem where memory bank, the memory does not exist?
- In that scenario, you have to reason through everything with first principles.
- And that core without the memory system is what I think people refer to as the cognitive core, an intelligence system which is only reasoning only, and it does not necessarily need to remember things.
- It can reason through a problem alone and can build up its own memory bank as it goes along.
- So the reason I came upon the idea of this essay in the first place was I observed that AIs regurgitate their training data in code bases.
- They will all write terrible code, but seemingly they score very differently on benchmarks.
- So the question comes up is that what is it about the model which is able to help it do better on the benchmarks?
- What is it that the benchmark is actually testing for?
- And if the smaller model is able to think through things, then it— and just because it can think, does it mean it makes it equally intelligent to the smarter model?
- So the inference is that the intelligence loop is sort of lopsided in these two cases.
- The capability exists in both models, but it is unequally distributed.
- One is able to make better use of its memory bank, because we are assuming that these two models both experience the same exact training data, but one is able to infer better on top of it and has better reasoning capabilities.
- And so, the answer I came upon was that it is regurgitating its post-training data.
- And the second thing is it is able to reason through things, but not as capably as, like a larger model would be able to.
- They do not have the judgment, or like the value judgment to think about what good versus bad means.
- And the training data does not tell them what good code means versus what bad code means.
